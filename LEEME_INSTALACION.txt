FORESTAL CONTROL ALPHA 06 — iPHONE / HTTPS

PUBLICAR EN GITHUB PAGES
1. Descomprime el ZIP.
2. En GitHub, crea un repositorio nuevo, por ejemplo: forestal-control.
3. Sube LOS CINCO ARCHIVOS de esta carpeta a la raíz del repositorio:
   index.html, manifest.webmanifest, service-worker.js, icon-192.png, icon-512.png.
4. En Settings > Pages, elige 'Deploy from a branch', rama 'main' y carpeta '/ (root)'.
5. GitHub mostrará el enlace HTTPS de la página. Normalmente tendrá un formato como:
   https://TU-USUARIO.github.io/forestal-control/
   (Es solo un EJEMPLO. El enlace real aparece en GitHub Pages).

EN IPHONE
1. Abre el enlace HTTPS en Safari.
2. Toca Compartir > Añadir a pantalla de inicio.
3. Entra desde el icono Forestal Control.

ADVERTENCIAS IMPORTANTES
- Este paquete publica el Alpha 06 anterior con el mismo funcionamiento y los mismos
  límites de seguridad. La pantalla de usuario/clave es un bloqueo local: no cifra los datos.
- Los registros locales de Windows NO viajan automáticamente al sitio HTTPS ni al iPhone.
  Haz respaldo JSON desde tu versión anterior e impórtalo en la nueva instalación.
- Los datos almacenados en Safari y los que guarda la app añadida a Inicio pueden ser
  independientes. Úsala siempre desde el mismo acceso, y exporta respaldos periódicos.
- El mecánico NO sincroniza automáticamente con el administrador a menos que configures
  un backend compartido. El módulo Supabase de Alpha 06 es PILOTO, no permite aplicar
  permisos de rol seguros en el servidor y no es apropiado para datos sensibles reales.
- GitHub Pages publica archivos de forma pública. Nunca subas archivos JSON de respaldo,
  contraseñas, claves privadas o información confidencial al repositorio.
- La app puede abrir ciertas pantallas sin internet una vez cacheada, pero la nube necesita
  conectividad. No confíes en el cache como respaldo.
